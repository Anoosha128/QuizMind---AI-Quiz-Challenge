# 🧠 QuizMind - AI Quiz Challenge

QuizMind is an interactive quiz application built with Python and Streamlit. It allows users to answer multiple-choice questions, track their score, and receive their final results through a simple and user-friendly interface.

## ✨ Features

* 🧠 Interactive multiple-choice quiz
* 📊 Real-time score tracking
* ➡️ Next question navigation
* ✅ Instant answer feedback
* 🏆 Final score and percentage
* 🔄 Restart quiz option
* 💻 Simple and responsive interface

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/QuizMind.git
```

Open the project folder:

```bash
cd QuizMind
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🎮 How It Works

1. Start the QuizMind application.
2. Read the displayed question.
3. Select one answer from the available options.
4. Click **Submit Answer**.
5. View your answer feedback.
6. Click **Next Question**.
7. Complete all questions.
8. View your final score and percentage.
9. Restart the quiz whenever you want.
